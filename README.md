# 💻 Meu Currículo Online - Portfólio

Um site de currículo e portfólio interativo, moderno e responsivo, desenvolvido com HTML5, CSS3 e JavaScript.
O projeto conta com um design escuro (*Dark Theme*), navegação fluida, efeitos de hover, seções retráteis para projetos e certificações,
e um layout responsivo adaptado para dispositivos móveis e desktop.

🚀 **Demonstração Online:** [Acesse o Projeto na Vercel]https://meu-curriculo-ten-gamma.vercel.app

📸 Destaques do Projeto

- **Layout Moderno & Tema Dark** com gradiente radial e detalhes em tom roxo (`#9333ea`).
- **Seção "Sobre Mim"** com tags visuais das principais tecnologias dominadas.
- **Barra Lateral de Competências** com acompanhamento suave ao rolar a página (`position: sticky`).
- **Acordeão de Projetos e Certificações** usando tags nativas HTML5 (`<details>` e `<summary>`).
- **Menu Rápido** para navegação direta às certificações.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura semântica e acessível do projeto.
- **CSS3** — Estilização moderna utilizando Flexbox, layouts responsivos (`@media`), gradientes radiais e `position: sticky`.
- **Font Awesome 6** — Ícones vetoriais integrados via CDN.
- **Google Fonts** — Tipografia estilizada com a fonte *Poppins*.
- **Vercel** — Hospedagem contínua e implantação automática (CI/CD).
